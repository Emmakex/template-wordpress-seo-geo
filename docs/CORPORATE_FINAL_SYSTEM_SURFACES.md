# Corporate Final System Surfaces

Status: implementation candidate

## Scope

The Corporate preset owns finished `single`, `archive` and `404` presentation surfaces in addition to its page compositions.

The neutral theme templates remain the fallback for every other preset. Corporate replacements are applied only when:

- the active preset is `corporate`;
- WordPress resolved the template from the Theme source;
- the template slug is `single`, `archive` or `404`;
- the bundled Corporate template source is readable.

Site Editor custom templates remain authoritative and are never overwritten by this runtime.

## Product rule

A clean Corporate installation must look like a finished bespoke website before client content is hydrated. System surfaces are part of that requirement; a polished Home with generic Single, Archive or 404 templates is not considered 99% finished.

## Surface contract

### Single

- one dynamic post H1;
- taxonomy/date/author context;
- featured image when available;
- native post content;
- author provenance;
- previous/next internal navigation.

### Archive

- dynamic archive H1;
- optional term description;
- crawlable native post grid;
- native pagination;
- no remote runtime dependency.

### 404

- one page-level H1;
- locale-aware EN/ES recovery copy;
- safe home URL generated by WordPress;
- native site search;
- no client-content placeholders or fabricated evidence.

## Safety and performance

These surfaces reuse the accepted Corporate visual language and existing CSS. They add no project JavaScript, remote font, external media, Schema authority or relaxed performance budget.

Validation lives in `scripts/ci/validate-corporate-system-surfaces.php` and is executed by Corporate Page Pipeline CI.
