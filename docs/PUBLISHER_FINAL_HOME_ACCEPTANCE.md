# Publisher Home acceptance checklist

DS-5A may merge only when all of the following remain true:

- existing Publisher semantic contract passes unchanged;
- final Home contract passes for EN/ES placeholder parity and publication blocking;
- no H1 is introduced by the preset-owned Home pattern;
- no remote assets, fonts, scripts or Schema payloads are embedded;
- no author, source, date, readership or subscriber evidence is fabricated;
- Publisher opts into the shared Design System without regressing the accepted SaaS contract;
- PHP syntax, WPCS and PHPStan are green;
- WordPress activation and zero-plugin self-contained smoke are green;
- accessibility/responsive and native multilingual acceptance are green;
- Lighthouse budgets pass without threshold changes.

A green DS-5A closes the Publisher Home only. Inner pages and system surfaces remain separate microphases.
